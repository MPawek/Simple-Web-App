# Simple Web App with CI/CD and Containerization

## Overview
This project is a lightweight backend web service built in **Go** using the **Fiber** framework, designed to demonstrate production-oriented software engineering practices. It exposes a simple REST API while emphasizing **containerization, automated CI/CD, and reproducible deployment** rather than application complexity.

The project was originally developed as part of a **take-home technical interview**, with a focus on code clarity, automation, and deployment readiness.

---

## Key Features
- RESTful API implemented in **Go (Fiber)**
- Fully containerized using **Docker**
- Automated **CI/CD pipeline** using GitHub Actions
- Continuous build, test, and image publishing on every push to `main`
- Designed for consistent behavior across local and deployed environments

---

## Tech Stack
- **Language:** Go  
- **Web Framework:** Fiber  
- **Containerization:** Docker  
- **CI/CD:** GitHub Actions  
- **Deployment:** OCI-compliant container registry / cloud VM  

---

## Architecture & Design Decisions

### Minimal API Surface
The application intentionally exposes a simple endpoint that returns a dynamically generated JSON response. This keeps the focus on **infrastructure, automation, and reliability** rather than business logic.

### Container-First Development
A Dockerfile defines a reproducible runtime environment, ensuring:
- consistent builds across machines,
- minimal dependency drift,
- straightforward deployment to any container-compatible platform.

### Automated CI/CD Pipeline
A GitHub Actions workflow is triggered on pushes to the `main` branch and performs the following steps:
1. Build the Go application
2. Build and tag a Docker image
3. Run basic functionality checks
4. Push the image to an OCI-compliant container registry

This mirrors a real-world continuous delivery workflow and reduces the risk of broken deployments.

## Running the Application Locally

### Prerequisites
- Go (installed locally) **or**
- Docker

### Option 1: Run with Go
```bash
go run main.go
```

### Option 2: Run with Docker
```
docker build -t simple-web-app .
docker run -p 8080:8080 simple-web-app
```
The service will be available at
http://localhost:8080

### Testing the API
You can test the API using a browser or curl
```
curl http://localhost:8080
```
The response will be a JSON payload generated by the service.
